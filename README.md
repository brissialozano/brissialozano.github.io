## Description
This portfolio showcases my academic background, technical skills, and project deliverables for IS 3060 at the University of Utah. It features a responsive layout designed for both desktop and mobile viewports.

## Technologies Used
* **HTML5:** Semantic structure and content
* **CSS3 & Bootstrap 5:** Responsive grid layout, navigation, and custom styling
* **Git & GitHub:** Version control and repository management
* **GitHub Pages:** Web hosting and deployment
